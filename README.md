# Ledium Client

Ledium Client is a lightweight Minecraft client focused on performance, customization, and quality-of-life improvements for Java Edition. The goal of the project is to provide a clean, fast, and easy-to-use experience while remaining simple to install and update.

## Features

* Sus Chunk
* Esp
* Base Finder
* Auto Log-Off
* Skeleton Spawner PackUp 
* ScoreBoard Changer
* Fake Pay
* And way more!

## Installation

1. Download the latest release of this repository.
2. Make sure you have **Minecraft Java Edition** installed.
3. Install the required Java version (Java 17 or the version listed in the release notes).
4. Put the .jar file in your mods folder.
5. Start up minecraft and put your purchased key in and enjoy!

## System Requirements

* **OS:** Windows 10/11 
* **Java:** 17 or newer
* **Minecraft:** Java Edition

### The client won’t start

* Make sure Java is installed.
* Verify that you downloaded the latest release.

### Minecraft crashes on launch

* Check that the selected Minecraft version is supported.
* Remove conflicting mods or launchers.
* Restart the client and try again.
